⏱️ TOTAL TIME: 6-7 MINUTES


STEP 1: Get GitHub Token [2 MIN]
─────────────────────────────────

1. Open: https://github.com/settings/tokens
2. Click: "Generate new token (classic)"
3. Enter: Your GitHub password
4. Token name: vercel-deploy
5. Scopes: Check ONLY "repo"
6. Scroll down, click: "Generate token"
7. **COPY the token** (save it temporarily!)


STEP 2: Create GitHub Repo [1 MIN]
───────────────────────────────────

1. Open: https://github.com/new
2. Repository name: student-database
3. Description: (optional)
4. Click: "Create repository"


STEP 3: Push Code [1 MIN]
─────────────────────────

1. Open PowerShell in your project folder

2. Run these EXACT commands:

   cd "c:\Users\ADMIN\Desktop\student data base system"
   
   git remote add origin https://YOUR-USERNAME:YOUR-TOKEN@github.com/YOUR-USERNAME/student-database.git
   
   git branch -M main
   
   git push -u origin main

3. REPLACE these:
   - YOUR-USERNAME = your GitHub username
   - YOUR-TOKEN = the token from Step 1


EXAMPLE:
─────────

If your GitHub username is "john-doe"
And your token is "ghp_abcdefg123xyz"

Then run:

   git remote add origin https://john-doe:ghp_abcdefg123xyz@github.com/john-doe/student-database.git
   
   git branch -M main
   
   git push -u origin main


STEP 4: Wait for Vercel [2-3 MIN]
──────────────────────────────────

1. Open: https://vercel.com/dashboard
2. Find your project: student-database
3. Click: "Deployments"
4. Watch status bar:
   - Status: Building...
   - (wait ~2 minutes)
   - Status: Ready ✓
5. Click preview URL when "Ready"

OPTIONAL: Add Data Storage [+5 MIN]

Without MongoDB: Data disappears on refresh
With MongoDB: Data stays forever

To add:

1. Go: https://www.mongodb.com/cloud/atlas
2. Sign up (FREE)
3. Create M0 cluster
4. Create user: admin / yoursecondpassword
5. Get connection string
6. Vercel → Settings → Environment Variables
7. Add: MONGODB_URI = your connection string
8. Redeploy

Total: +5 minutes
